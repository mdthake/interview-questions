The Amazon API Gateway operations team needs to analyze activity records
across numServices different managed services to track utilization and ensure
consistent responsiveness.

The services are indexed from 1 to numServices, and the records are provided
as a 2D array activityRecords of size k, where activityRecords[j] = [service_ID,
eventTime] denotes that an invocation was made to the service with ID
service_ID at the time eventTime.

You are given an integer numServices, a 2D integer array activityRecords, an
integer observationWindow (representing a lookback duration), and an array of
evaluationTimes containing p queries.

For each evaluationTimes[j], determine the number of services that did not
receive an invocation in the time interval [evaluationTimes[j] -
observationWindow, evaluationTimes[j]]. Return an array of length p containing
the result of each of the queries.

Note: If for some query all the numServices received invocation in the given
time interval for that query, then answer is 0.

Example
Suppose numServices = 3, observationWindow = 5, activityRecords[] = [[1, 3],
[2, 6], [1, 5]], and evaluationTimes[] = [10, 11]

    evaluationTimes | Time Interval        | Received an invocation | Not receiving an invocation
    10              | [10 - 5, 10] = [5, 10] | 1, 2                 | 3
    11              | [11 - 5, 11] = [6, 11] | 2                    | 1, 3

    - For evaluationTimes[0] = 10, services 1 and 2 had invocations at
      eventTimes 5 and 6, respectively, which fall in the interval [5, 10].
      Service 3 did not receive any invocations in the given interval. Thus,
      answer for this evaluationTimes is 1.
    - For evaluationTimes[1] = 11, service 2 had an invocation at eventTime 6,
      which falls in the interval [6, 11]. Services 1 and 3 did not receive
      any invocations in that interval. Thus, answer for this evaluationTimes
      is 2.

calculateIdleServiceCount has the following parameter(s):
    int numServices: the number of managed services
    int activityRecords[k][2]: each row is [service_ID, eventTime]
    int evaluationTimes[p]: the query times
    int observationWindow: the lookback duration

Returns

    each query
